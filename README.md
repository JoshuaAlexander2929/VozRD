# VozRD

Foro web de periodismo ciudadano hecho con Flask y SQLite, donde los usuarios pueden registrarse, iniciar sesión y publicar.

## Tecnologías
- Python y Flask
- SQLite
- Flask-Login (autenticación de usuarios)
- HTML y CSS, con un sistema de diseño visual propio y logo ilustrado a mano

## Páginas
- Inicio (listado de publicaciones)
- Registro e inicio de sesión
- Crear publicación
- Vista de publicación

## Cómo ejecutarlo
bash
git clone https://github.com/JoshuaAlexander2929/VozRD.git
cd VozRD
pip install flask flask-login
python app.py

Luego abre http://127.0.0.1:5000 en tu navegador.
